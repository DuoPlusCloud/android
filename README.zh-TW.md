## 關於 DuoPlus

[DuoPlus 雲端手機](https://www.duoplus.net/)是適用於多帳號管理、社群媒體行銷與行動業務營運的雲端 Android 平台。

DuoPlus 採用真實 ARM 硬體，提供獨立的 Android 雲端手機環境，無須維護多支實體手機，協助個人與團隊管理行動應用程式、整理多個帳號，並透過共用雲端裝置進行協作。

### 平台功能特色

- **Android 雲端手機：** 在採用真實 ARM 硬體的雲端裝置上執行行動應用程式。
- **獨立裝置環境：** 使用不同雲端手機分別管理帳號與行動工作流程。
- **多帳號管理：** 支援多個社群媒體帳號與商務帳號的營運。
- **應用程式批次管理：** 在雲端裝置上批次安裝、啟動及解除安裝應用程式。
- **團隊協作：** 與團隊成員共用雲端裝置。
- **工作流程自動化：** 探索操作同步、RPA 與 API 功能。

前往 [DuoPlus 官方網站](https://www.duoplus.net/)瞭解功能、使用情境與方案。以上介紹適用於 DuoPlus 平台整體，Android 用戶端的實際功能可能因版本而異。

## 如何安裝 APK

1. 在 Android 裝置上開啟下載的 APK 檔案。
2. 若系統提示，請允許瀏覽器或檔案管理員安裝來自此來源的應用程式。
3. 依照畫面指示完成安裝。
4. 啟動 **DuoPlus**。

安裝完成後，可以關閉此安裝權限。
