## เกี่ยวกับ DuoPlus

[DuoPlus Cloud Phone](https://www.duoplus.net/) คือแพลตฟอร์ม Android บนคลาวด์สำหรับการจัดการหลายบัญชี การตลาดบนโซเชียลมีเดีย และการดำเนินงานธุรกิจผ่านแอปมือถือ

DuoPlus ใช้ฮาร์ดแวร์ ARM จริงเพื่อให้บริการสภาพแวดล้อมโทรศัพท์ Android บนคลาวด์ที่แยกจากกัน โดยไม่จำเป็นต้องดูแลโทรศัพท์จริงหลายเครื่อง ช่วยให้บุคคลและทีมจัดการแอปมือถือ จัดระเบียบหลายบัญชี และทำงานร่วมกันบนอุปกรณ์คลาวด์ได้

### ฟีเจอร์เด่นของแพลตฟอร์ม

- **โทรศัพท์ Android บนคลาวด์:** เรียกใช้แอปมือถือบนอุปกรณ์คลาวด์ที่ใช้ฮาร์ดแวร์ ARM จริง
- **สภาพแวดล้อมแยกจากกัน:** จัดการบัญชีและขั้นตอนการทำงานบนโทรศัพท์คลาวด์แต่ละเครื่องแยกกัน
- **การจัดการหลายบัญชี:** รองรับการดูแลบัญชีโซเชียลมีเดียและบัญชีธุรกิจหลายบัญชี
- **การจัดการแอปแบบกลุ่ม:** ติดตั้ง เปิด และถอนการติดตั้งแอปบนอุปกรณ์คลาวด์หลายเครื่อง
- **การทำงานร่วมกันเป็นทีม:** แชร์อุปกรณ์คลาวด์กับสมาชิกในทีม
- **ระบบอัตโนมัติ:** สำรวจฟีเจอร์ซิงค์การทำงาน RPA และ API

ดูฟีเจอร์ รูปแบบการใช้งาน และแพ็กเกจได้ที่ [เว็บไซต์ DuoPlus](https://www.duoplus.net/) ฟีเจอร์ข้างต้นเป็นภาพรวมของแพลตฟอร์ม DuoPlus โดยฟีเจอร์ที่ใช้ได้ในแอป Android อาจแตกต่างกันตามเวอร์ชัน

## ดาวน์โหลด DuoPlus สำหรับ Android

### Google Play

[ดาวน์โหลด DuoPlus บน Google Play →](https://play.google.com/store/apps/details?id=com.duoplus.app)

ทำตามขั้นตอนการติดตั้งที่แสดงในร้านค้า

### ดาวน์โหลด APK โดยตรง

[ดาวน์โหลด APK เวอร์ชันล่าสุด →](https://github.com/DuoPlusCloud/android/releases/latest)

เปิดหน้ารุ่นล่าสุด ไปที่ส่วน **Assets** แล้วดาวน์โหลดไฟล์ `.apk` ลงในอุปกรณ์ Android ตรวจสอบข้อกำหนดด้านความเข้ากันได้และคำแนะนำในการติดตั้งในบันทึกประจำรุ่น

## วิธีติดตั้ง APK

1. เปิดไฟล์ APK ที่ดาวน์โหลดบนอุปกรณ์ Android
2. หากระบบร้องขอ ให้อนุญาตเบราว์เซอร์หรือแอปจัดการไฟล์ติดตั้งแอปจากแหล่งนี้
3. ทำตามคำแนะนำบนหน้าจอเพื่อติดตั้งให้เสร็จสมบูรณ์
4. เปิด **DuoPlus**

คุณสามารถปิดสิทธิ์การติดตั้งนี้ได้หลังจากติดตั้งเสร็จ

## วิธีอัปเดต

- **Google Play:** เปิด [หน้าร้านค้าของแอป](https://play.google.com/store/apps/details?id=com.duoplus.app) แล้วแตะ **อัปเดต** เมื่อมีเวอร์ชันใหม่
- **APK จาก GitHub:** ดาวน์โหลดและติดตั้ง [APK เวอร์ชันล่าสุด](https://github.com/DuoPlusCloud/android/releases/latest) พร้อมทำตามคำแนะนำเพิ่มเติมของรุ่นนั้น

ควรอัปเดตผ่านแหล่งเดียวกับที่ใช้ติดตั้งแอปครั้งแรก
